# Loja de Roupas

Criamos em conjunto um site para a loja Cintia Caetano Maison, buscando ampliar as vendas da mesma e criar um espaço a mais de divulgação. O projeto foi entregue como trabalho conclusivo do 2 semestre de Ciência da Computação na Escola de Engenharia de Piracicaba (EEP).

## Como utilizar

Para utilizar, basta clicar no link a seguir e você será redirecionado para o site já funcionando: https://enzozambon1.github.io/cintia-maison/

## Funcionalidades

Sistema completo de loja. Capaz de adicionar múltiplos itens à sacola, selecionar diferentes tamanhos, simulação de sistema de pagamento (em breve atualizado para pagamentos funcionais), simulação de frete, sistema de cupom funcional (CINTIA30), geração de código de rastreamento e rastreio, sistema de favoritar peças, sistema de busca com filtros e responsividade geral.

## Requisitos

Apenas deixar o JavaScript habilitado e ter Internet :)
